# 2048

An offline 2048 function for Magic Box. Create a ZIP containing `manifest.json`, `index.html`, and `game.js` at its root, then import it using Magic Box.

Use swipes to move and merge tiles on the 4 by 4 board. Each merge adds the resulting tile value to the score. Use New Game to restart. The game reports when a 2048 tile is reached or no moves remain.

The ready-to-import package is `2048.zip`.
