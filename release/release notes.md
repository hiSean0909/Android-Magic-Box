# Release Notes

## v0.2

- Add an Uninstall button and enable newly installed or reinstalled plugins by default, while preserving the enabled state on updates.
- Add an About action to display and copy the project GitHub address.

## v0.3

- Add the Plugins list and import menu, update Search, and reserve screen edges in the host and plugins.
- Add plugin cards and move plugin management to each card.
- Update About dialog buttons and add copy and close actions to the plugin repository URL dialog.

## v0.4

- Bundle plugins from the built-in plugin directory and preserve existing plugins and uninstall choices.
- Compare plugin standard versions during local import and show an appropriate result message.
- Add plugin export, About details, updated card controls, descriptions, and icons.
- Search plugin names and descriptions, listing enabled plugins first and prioritizing name matches.
- Add a custom application launcher icon.
